**RockPaperAi 1.0.3: charts from the shared kit.**

- New chart "Winning streaks of matches and record": how many matches in a row you won (more rounds than the AI) and your best streak.
- Statistics charts now come from the shared aikit 0.2.0 used by every game in the AI Game Room: labels that would not fit move to the next line instead of being cut, and with no matches yet each chart says in words what will appear.
- New tests: chart labels stay whole in both themes, both languages, wide and narrow window; 3 new mutants, all caught; 263 tests.

Files: `RockPaperAi-1.0.3-setup.exe` and `RockPaperAi-1.0.3-portable.zip`. The builds are not code-signed, so SmartScreen may warn on first start.
